# רשימת קניות

אפליקציית PWA אישית לניהול רשימת קניות קבועה, עם חלוקה לפי חנות (רמי לוי / אושר עד / שופרסל / ויקטורי / קרפור / נטו חיסכון / סופר 100 / פאפא) ותדירות (כל שבוע / לא כל שבוע). הסניפים הרלוונטיים נמצאים באשדוד: רמי לוי, אושר עד ושופרסל באזור התעשייה, ויקטורי ליד חוף הים.

**ארכיטקטורה:** אתר סטטי (HTML/CSS/JS בלבד, בלי שרת) שמדבר ישירות מול [Supabase](https://supabase.com) — מסד נתונים (Postgres) + התחברות משתמשים. אין תלות ב-Flask/Railway.

## שלב א' (המצב הנוכחי)
- ניהול קטלוג מוצרים קבועים לפי קטגוריה, חנות ותדירות
- רשימת קניות שבועית שמתמלאת אוטומטית ממוצרים קבועים, ואפשר להוסיף אליה מוצרים חד-פעמיים
- סימון מוצרים שנקנו, וכפתור "סיימתי לקנות" לאיפוס הרשימה
- התחברות עם אימייל/סיסמה (Supabase Auth) — מוכן לשיתוף עם עוד בן משפחה בעתיד
- מותקן כאפליקציה בטלפון (PWA) עם תמיכה בסיסית באופליין

## הקמה (חד-פעמי)

### 1. יצירת פרויקט Supabase
- היכנס ל-[supabase.com](https://supabase.com), צור חשבון/התחבר, ולחץ **New Project**
- בחר סיסמה למסד הנתונים (תישמר אוטומטית, לא צריך לזכור אותה) ואזור קרוב (Europe)

### 2. הרצת סכימת המסד
- בתפריט הצד: **SQL Editor** → **New query**
- העתק את התוכן של `sql/schema.sql` מהריפו הזה, הדבק, ולחץ **Run**
- זה יוצר את טבלת `products` עם הרשאות גישה (Row Level Security) שמאפשרות רק למשתמשים מחוברים לקרוא/לכתוב

### 3. קבלת מפתחות החיבור
- **Project Settings → API**
- העתק את **Project URL** ואת ה-**anon public key**
- ערוך את `static/supabase-client.js` והחלף את `REPLACE_ME_SUPABASE_URL` ו-`REPLACE_ME_SUPABASE_ANON_KEY` בערכים האלה
  (המפתח הזה בטוח לחשיפה בצד לקוח — הוא מוגן ע"י ה-RLS policies שהגדרנו, לא נותן גישה בלי התחברות)

### 4. יצירת משתמשים
כברירת מחדל הרשמה עצמית פתוחה. מומלץ לכבות אותה ולהזמין רק את עצמך (ובעתיד את בת/בן הזוג):
- **Authentication → Providers → Email** → כבה "Allow new users to sign up"
- **Authentication → Users → Add user → Create new user** — הזן אימייל וסיסמה עבור עצמך

### 5. פריסה (GitHub Pages)
- ב-GitHub, בריפו הזה: **Settings → Pages**
- תחת **Build and deployment → Source** בחר **Deploy from a branch**
- **Branch**: `main`, תיקייה `/ (root)` → **Save**
- אחרי דקה-שתיים תקבל כתובת כמו `https://avivamou-ai.github.io/shopping-list-app/`
- פתח את הכתובת בטלפון והוסף למסך הבית (Add to Home Screen)

## הרצה מקומית
פשוט לפתוח את `index.html` בדפדפן (או `python3 -m http.server` מתוך התיקייה) — אחרי שמילאת את `static/supabase-client.js`.

## שלב ב' (בתכנון)
השוואת מחירים בין הסניפים על סמך קובצי שקיפות המחירים הרשמיים שרשתות גדולות מחויבות לפרסם לפי חוק. מקורות ידועים נכון לעכשיו:
- **רמי לוי, אושר עד** — פורטל משותף `url.publishedprices.co.il` (כניסה עם שם משתמש בלבד, ללא סיסמה)
- **שופרסל** — פורטל עצמאי `prices.shufersal.co.il`
- **ויקטורי** — פורטל `laibcatalog.co.il`
- **קרפור** — פורטל עצמאי `prices.carrefour.co.il`
- **נטו חיסכון, סופר 100** — טרם אומת המקור; צריך לבדוק בעת המימוש
- **פאפא** — רשת מקומית קטנה, כנראה לא מחויבת בחוק שקיפות המחירים; ככל הנראה יידרש הזנת מחירים ידנית (לא בעדיפות כרגע)

המימוש בפועל ידרוש הורדת קבצי ה-XML היומיים לסניפים הספציפיים באשדוד, התאמת מוצרים לברקוד, ותצוגת ההשוואה בממשק.

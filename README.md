# רשימת קניות

אפליקציית PWA אישית לניהול רשימת קניות קבועה, עם חלוקה לפי חנות (רמי לוי / אושר עד / ויקטורי / פאפא) ותדירות (כל שבוע / לא כל שבוע).

## שלב א' (המצב הנוכחי)
- ניהול קטלוג מוצרים קבועים לפי קטגוריה, חנות ותדירות
- רשימת קניות שבועית שמתמלאת אוטומטית ממוצרים קבועים, ואפשר להוסיף אליה מוצרים חד-פעמיים
- סימון מוצרים שנקנו, וכפתור "סיימתי לקנות" לאיפוס הרשימה
- מותקן כאפליקציה בטלפון (PWA) עם תמיכה בסיסית באופליין

## שלב ב' (בתכנון)
השוואת מחירים בין הסניפים על סמך קובצי שקיפות המחירים הרשמיים (רמי לוי ואושר עד דרך פורטל publishedprices.co.il, ויקטורי דרך laibcatalog.co.il). פאפא מרקט הוא רשת מקומית קטנה שכנראה אינה מחויבת בחוק שקיפות המחירים, ולכן המחירים שלו יוזנו ידנית.

## הרצה מקומית
```bash
pip install -r requirements.txt
python app.py
```

## פריסה
מוכן לפריסה ב-Railway (`railway.toml` + `Procfile`) עם gunicorn.
